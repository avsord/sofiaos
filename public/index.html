CONTROLE E TRANSPARÊNCIA

Configuração.

No uso normal, a Sofia escolhe o filtro automaticamente. Aqui ficam os controles técnicos.

Configuração dos filtros da IA

No uso normal, a Sofia escolhe o filtro automaticamente. Compartilhado é o projeto que você autorizou para conteúdo geral e benefícios de compartilhamento. Privado é o projeto que ficou fora dessa seleção na OpenAI. As chaves são diferentes e nunca são exibidas depois de salvas.

A Sofia não consegue consultar sua configuração de Sharing na OpenAI. A confirmação abaixo é manual e deve refletir o que você acabou de configurar na Platform.

Chaves dos projetos

Para Privado/Compartilhado, o teste consulta apenas o endpoint de modelos. Para Uso da OpenAI, a chave Admin é validada no endpoint oficial de Usage da organização. Nenhuma conversa, memória ou dado pessoal é enviado durante a validação. A chave Admin é necessária para sincronizar os números do painel da OpenAI; uma chave comum de projeto não tem acesso ao Usage da organização.

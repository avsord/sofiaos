# Sofia OS v118 — Agenda Calendar Viewer

A Agenda foi reorganizada como um viewer de calendário.

## O que mudou
- visão mensal em grade, no padrão de uso de um calendário moderno;
- navegação Hoje / mês anterior / próximo mês;
- visão Programação em lista cronológica;
- eventos, compromissos, lembretes, tarefas com data e outros registros com campo de data aparecem juntos;
- filtros por origem;
- clicar num item abre o registro original;
- a faixa do Resumo com X sobreposto e subpáginas fechadas por padrão da v117 foram preservadas;
- documentação bruta continua preservada.

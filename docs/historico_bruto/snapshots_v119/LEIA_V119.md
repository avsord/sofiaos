# LEIA V119

## Agenda
A Agenda agora é interativa. O calendário é a visualização das entidades datadas da Sofia, e não uma cópia separada dos dados.

- clique em um dia para criar;
- clique em item existente para editar;
- arraste um item entre dias para reagendar;
- Tarefa continua vinculada à área Tarefas;
- Evento/Lembrete continuam vinculados ao registro original.

## Google Calendar
A integração externa ainda não é executada. Foram adicionados campos de vínculo/sincronização em tarefas e os eventos/lembretes já mantêm IDs/estado de sincronização para permitir uma futura integração bidirecional sem duplicar registros.

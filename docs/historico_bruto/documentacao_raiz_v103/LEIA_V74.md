# Sofia OS v74 — Ajustes desta entrega

## Alterações aplicadas
- Correção visual do menu lateral para alinhar melhor os textos e ícones.
- Botão **APLICATIVOS DA SOFIA** com altura e largura consistentes com os itens abaixo.

# Sofia OS v102 — notificações corrigidas

- O sino abre a prévia flutuante ao passar o mouse, sem exigir clique.
- A prévia aparece imediatamente usando o estado já carregado da tela e atualiza em seguida pelo backend.
- Quando não há notificações, mostra **“Você não tem notificações.”** centralizado.
- O link **Ver todas** fica no canto superior e abre a central completa.
- A central completa separa as notificações primeiro por **Área** e, dentro de cada área, por **Origem**.
- Cada item detalhado mantém estado, categoria, importância, data, vínculo e ações.
- Cache do front atualizado para v102 para evitar o navegador reutilizar JS/CSS da versão anterior.

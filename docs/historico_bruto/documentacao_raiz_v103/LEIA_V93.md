# Sofia OS v93 — ícones presos ao topo da página

- Os botões `+`, engrenagem e `…` voltaram para dentro do cabeçalho da página Particular.
- Eles permanecem na posição original quando a página está no topo.
- Ao rolar para baixo, sobem junto com o cabeçalho e desaparecem da tela.
- Eles não ficam mais flutuando por cima do conteúdo.
- Os assets usam `v=93` para impedir cache da versão anterior.

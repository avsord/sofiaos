# Sofia OS v108 — páginas limpas estilo Notion

Esta versão simplifica a interface de páginas normais e subpáginas sem perder recursos nem documentação histórica.

## Alterações principais
- ações redundantes removidas da área principal da página;
- capa clicável, com controle de troca discreto no hover;
- ícone continua clicável para troca;
- subpáginas exibidas como cartões limpos;
- botões de topo centralizados e um pouco mais altos;
- documentação bruta integral preservada.

## Aplicar esta versão
1. Pare a Sofia com `Ctrl+C`.
2. Rode `ATUALIZAR_SOFIA.cmd` desta pasta.
3. Ligue novamente a Sofia.
4. No navegador, faça `Ctrl+F5` uma vez.

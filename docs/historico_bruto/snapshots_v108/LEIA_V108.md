# LEIA V108

## O que mudou
- páginas normais e subpáginas ficaram mais limpas e próximas do padrão do Notion;
- a faixa intermediária com ações redundantes foi removida da tela principal;
- capa agora é alterada clicando na própria capa, com botão discreto no hover;
- ícone continua sendo alterado ao clicar no próprio ícone;
- lista de subpáginas foi simplificada para cartões limpos, sem a faixa e as linhas antigas;
- botões do topo (+, engrenagem e mais ações) foram centralizados e movidos um pouco para cima.

## Instalação
1. Pare a Sofia com `Ctrl+C`.
2. Execute `ATUALIZAR_SOFIA.cmd`.
3. Inicie novamente com o comando padrão do projeto.
4. Faça `Ctrl + F5` no navegador uma vez.

## Observações
- a documentação bruta do projeto foi preservada;
- templates e outras ações secundárias continuam acessíveis pelo menu `•••`;
- o conteúdo, memória, `.env`, `data` e `INICIAR_SOFIA.cmd` local continuam preservados.

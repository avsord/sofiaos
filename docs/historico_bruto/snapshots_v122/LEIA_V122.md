# LEIA V122

## Ajuste desta versão
A barra de scroll dos menus laterais agora é fina e permanece visualmente presente, seguindo a referência do Notion. Ela não some ao entrar em uma subpágina nem depende do hover para ganhar cor.

## Aplicação
1. Pare a Sofia com `Ctrl+C`.
2. Execute `ATUALIZAR_SOFIA.cmd`.
3. Ligue novamente a Sofia.
4. Faça `Ctrl + F5` uma vez no navegador.

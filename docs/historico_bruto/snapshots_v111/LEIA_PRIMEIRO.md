# Sofia OS v111 — espaçamento dos blocos

Correção pontual no editor de páginas: o texto não fica mais colado aos controles `+` e de arrastar.

## Mantido
- capa e ícones da v110;
- placeholders só aparecem no hover;
- documentação bruta preservada.

## Aplicar
1. Pare a Sofia com `Ctrl+C`.
2. Rode `ATUALIZAR_SOFIA.cmd`.
3. Ligue novamente.
4. Faça `Ctrl + F5` uma vez.

# Sofia Android 0.3.10 / server 141.0.0

This release retains the approved 0.3.9 native pager and touch-down navigation. The purple menu pill, icon and caption now derive their swipe weights from a native Animated scroll graph, shrinking/growing with the finger rather than waiting for momentum completion. Taps trigger a separate interruptible spring without delaying page navigation. Reduced-motion accessibility suppresses scale transforms.

Pages now autosave all editing operations, including undo/redo, checkboxes, title, blocks, icon and cover. Saves are serialized per page; newer typing cannot be overwritten by an earlier response. Pending drafts are stored in account/server-scoped app storage and can be restored after reopening; they are not represented as end-to-end encrypted. A server revision conflict requires an explicit choice, never a blind overwrite. Clean empty inputs reveal controls on focus. Subpage branches default closed and persist explicit expansion locally. Cover presets, emoji/symbol icons and an explicit system photo picker write the same page fields used by the site.

App and site share a server-side owner conversation cursor and refresh authoritative history windows every two seconds while active, with tombstones for deleted older messages. Drafts and in-progress recording block unsolicited conversation switching. Test/simulator/other-contact/protected conversations are excluded from the shared personal cursor. New read/select/delete APIs retain the existing cookie/CSRF or bearer authentication. Selection is activated by a message long press, supports multiple rows, and displays a top trash action only in selection mode. Deletion is explicitly confirmed; invalid/cross-thread IDs are rejected before any mutation, and individual failures are reported rather than hidden.

Validation before publishing: 66 app unit/interaction tests and 148 backend tests passed locally. Full TypeScript checks, locked dependency installation, Android release compilation and emulator install-over-0.3.9/login smoke test are CI gates. The interaction tests use numerical/hook stubs and do not measure physical-device FPS or verify the entire authenticated UI on the user's device. Image picker interaction and visual motion still require device acceptance.

Package remains com.avsord.sofiaapp. VersionCode 15. Release discovery prefix remains sofia-android-v. Existing signing, password, account, private-filter and history files are preserved. Server version 141.0.0 must be deployed before the APK release step.

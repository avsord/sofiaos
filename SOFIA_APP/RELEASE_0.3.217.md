# Sofia OS Android 0.3.217

Atualização automática a partir da 0.3.57.

Package com.avsord.sofiaapp; versionCode 222. Atualização por cima, sem desinstalar nem limpar dados. O servidor (Railway) também é atualizado.

- Contas: toda conta/receita fixa cadastrada aparece na lista (Contas fixas / Receitas fixas) em qualquer mês, igual às outras - a que começa depois diz de quando é ("a partir de novembro" ou "de novembro a março"), fora do total do mês.
- Contas: o que é avulso e vence nos próximos meses aparece em "Próximos meses" - nada some por ser de outro mês.
- Cópias idênticas de uma conta/receita fixa (mesmo nome, valor, data e parcelas, sem pagamento) somem sozinhas; fica a mais antiga. Cópia com valor diferente continua no aviso "cadastrada N vezes" para você escolher.
